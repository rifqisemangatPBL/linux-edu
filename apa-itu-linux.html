FONDASI SISTEM OPERASI

Anatomi & Cara Kerja Sebenarnya dari Linux

Secara teknis, Linux bukanlah sistem operasi lengkap yang berdiri sendiri. Linux adalah sebuah Kernel — komponen inti terpenting yang menjembatani perintah aplikasi dengan komponen fisik mesin komputer Anda.

1. Kernel Linux

Diciptakan oleh Linus Torvalds (1991)

Kernel bertanggung jawab langsung atas tugas-tugas tingkat rendah: mengalokasikan RAM ke proses, mengatur antrean eksekusi di CPU, berbicara dengan driver hard disk, serta menjaga keamanan batas hak akses memori agar satu program tidak dapat merusak program lain.

Fokus: Performa, stabilitas, dan manajemen perangkat keras tanpa antarmuka langsung ke pengguna.

2. Ekosistem GNU (Userland)

Digagas oleh Richard Stallman (1983)

Kernel saja tidak bisa digunakan oleh manusia tanpa alat perantara. GNU menyediakan shell terminal (bash), compiler C (gcc), pustaka C (glibc), dan perintah utilitas harian seperti ls, cp, rm, cat.

Gabungan Keduanya: Menghasilkan apa yang kita kenal sebagai GNU/Linux.

Tempat Anda dan aplikasi berinteraksi sehari-hari

Layer 4: User Space (Aplikasi & Desktop)

Merupakan lingkungan non-privilege di mana browser (Firefox), code editor (VS Code), shell (Bash), dan desktop environment (GNOME/KDE) berjalan. Jika sebuah aplikasi di layer ini crash, sistem operasi dan kernel tetap berjalan normal tanpa blue-screen.

Analogi Nyata: Ibarat tamu di sebuah gedung yang hanya memiliki akses ke ruangan yang diizinkan tanpa bisa merombak instalasi listrik atau fondasi gedung.
KOMPONEN & TEKNOLOGI TERKAIT:
Firefox VS Code Bash Shell GNOME / KDE Plasma

Isolasi Keamanan Ketat

Aplikasi pengguna tidak bisa sembarangan memodifikasi memori kernel atau file sistem tanpa otorisasi hak akses root / sudo.

Kestabilan Tanpa Henti

Jika sebuah web server atau browser crash, proses tersebut bisa dimatikan seketika tanpa perlu merestart seluruh komputer atau server Anda.

Modular & Portabel

Kernel yang sama dapat berjalan di jam tangan pintar (smartwatch), laptop tipis, router jaringan, hingga superkomputer beribu inti prosesor.

HUBUNGAN KE MODUL BERIKUTNYA

Setelah Memahami Arsitekturnya, Apa Konsekuensinya?

Arsitektur kernel yang ketat ini memberikan Linux keunggulan mutlak dalam hal efisiensi RAM dan keamanan siber. Namun, hal ini juga menghadirkan tantangan bagi pengguna baru: adaptasi perintah terminal dan dukungan software komersial tertentu. Mari kita telaah secara objektif di Modul 2.
