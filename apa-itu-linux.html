FONDASI SISTEM OPERASI

Anatomi & Cara Kerja Sebenarnya dari Linux

Secara teknis, Linux bukanlah sistem operasi utuh yang berdiri sendiri, melainkan sebuah Kernel yang menjembatani instruksi perangkat lunak dengan komponen fisik mesin.

KOMPONEN INTI • 1991 RING 0 PRIVILEGE

1. Kernel Linux (Linus Torvalds)

Kernel bertanggung jawab penuh atas tugas tingkat rendah: mengalokasikan halaman memori RAM ke setiap proses, mengatur penjadwalan eksekusi CPU, berkomunikasi dengan driver penyimpanan, serta menegakkan isolasi memori antar-program.

Fokus Utama: Manajemen sumber daya perangkat keras tanpa antarmuka langsung ke pengguna akhir.
USERLAND • 1983 RING 3 SPACE

2. Ekosistem GNU (Richard Stallman)

GNU menyediakan penerjemah perintah shell (bash), compiler C (gcc), pustaka runtime (glibc), dan utilitas dasar harian seperti ls, cp, rm, cat.

Sintesis Sistem: Kernel Linux + Utilitas GNU = GNU/Linux.
DIAGRAM INTERAKTIF 4-LAPIS

Alur Komunikasi Antar-Lapisan

Pilih salah satu lapisan pada tumpukan di sebelah kiri untuk menginspeksi peran teknis dan komponen yang terlibat.

Tempat Anda dan aplikasi berinteraksi sehari-hari

Layer 4: User Space (Aplikasi & Desktop)

Merupakan lingkungan non-privilege di mana browser (Firefox), code editor (VS Code), shell (Bash), dan desktop environment (GNOME/KDE) berjalan. Jika sebuah aplikasi di layer ini crash, sistem operasi dan kernel tetap berjalan normal tanpa gangguan menyeluruh.

Analogi Nyata: Ibarat tamu di sebuah gedung yang hanya memiliki akses ke ruangan yang diizinkan tanpa bisa merombak instalasi listrik atau fondasi gedung.
Komponen & Teknologi Terkait:
Firefox VS Code Bash Shell GNOME / KDE Plasma
IMPLIKASI ARSITEKTUR

Tiga Dampak Langsung Pemisahan Ring 0 & Ring 3

01 / ISOLASI HAK AKSES

Proteksi Memori Ketat

Aplikasi pengguna tidak dapat memodifikasi memori kernel atau berkas sistem tanpa otorisasi eksplisit melalui root / sudo.

02 / KESTABILAN PROSES

Pemulihan Tanpa Reboot

Jika proses di User Space berhenti merespons, proses tersebut dapat dihentikan seketika menggunakan sinyal SIGKILL tanpa merestart seluruh mesin.

03 / MODULARITAS KERNEL

Portabilitas Lintas Perangkat

Basis kode kernel yang sama beroperasi pada sistem embedded, laptop konsumen, router jaringan, hingga klaster superkomputer.

Transisi ke Modul 02

Konsekuensi Teknis di Dunia Nyata

Pemisahan kernel yang ketat memberikan efisiensi memori dan keamanan tinggi, namun membawa tantangan adaptasi perintah terminal serta ketersediaan perangkat lunak komersial. Telaah keseimbangannya pada Modul 02.
