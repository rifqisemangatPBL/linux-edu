LANGKAH PRAKTIK DI DUNIA NYATA

3 Jalur Instalasi Bebas Risiko ke Komputer Anda

Pilih skenario setup yang paling nyaman dengan spesifikasi hardware Anda saat ini:

METODE 1 • PALING AMAN

Virtual Machine (VirtualBox)

Menjalankan Linux sebagai aplikasi di dalam Windows atau macOS tanpa menyentuh susunan partisi disk fisik Anda.

1
Unduh Oracle VirtualBox gratis dari situs resminya.
2
Unduh file ISO Ubuntu LTS atau Linux Mint (sekitar 3-4 GB).
3
Buat VM baru, beri alokasi 4GB RAM dan 25GB virtual disk.
Kelebihan: Aman 100%, jika ada error tinggal hapus VM tanpa khawatir.
METODE 2 • TERBAIK WINDOWS

WSL 2 (Windows Subsystem)

Kernel Linux asli yang terintegrasi langsung di Windows 10/11. Pilihan nomor satu bagi programmer web & software developer.

1
Buka PowerShell sebagai Administrator.
2
Ketik perintah: wsl --install
3
Restart komputer dan nikmati terminal Linux asli di VS Code.
Kelebihan: Kecepatan native, akses file Windows dua arah tanpa lag.
METODE 3 • BARE METAL

Dual Boot Fisik

Memasang Linux berdampingan dengan Windows di drive fisik. Saat menyalakan PC, menu GRUB memungkinkan memilih masuk Windows atau Linux.

1
Sisihkan 50GB unallocated space via Disk Management Windows.
2
Flash ISO distro ke flashdisk menggunakan aplikasi Rufus.
3
Booting ke flashdisk dan pilih "Install alongside Windows".
Perhatian: Lakukan backup file penting ke flashdisk sebelum partisi.
