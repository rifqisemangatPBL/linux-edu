IMPLEMENTASI PERANGKAT KERAS

Tiga Jalur Instalasi Bebas Risiko

Pilih arsitektur pemasangan sesuai kebutuhan dan spesifikasi mesin Anda:

METODE 01 • ISOLASI VM

Virtual Machine (VirtualBox)

Menjalankan Linux di dalam lingkungan tervirtualisasi tanpa mengubah tabel partisi disk fisik host.

1
Pasang Oracle VirtualBox pada sistem operasi utama.
2
Unduh citra ISO Ubuntu LTS atau Linux Mint (~3–4 GB).
3
Alokasikan minimal 4GB RAM dan 25GB virtual disk.
Karakter: Isolasi penuh; snapshot memudahkan pemulihan konfigurasi.
METODE 02 • WINDOWS DEV

WSL 2 (Windows Subsystem)

Kernel Linux asli yang terintegrasi langsung di atas Windows 10/11 untuk alur kerja pengembangan perangkat lunak.

1
Buka PowerShell dengan hak akses Administrator.
2
Jalankan perintah: wsl --install
3
Restart sistem dan hubungkan langsung dengan VS Code.
Karakter: Performa I/O native dengan akses lintas sistem berkas.
METODE 03 • BARE METAL

Dual Boot Fisik

Instalasi berdampingan pada drive fisik yang dikelola oleh bootloader GRUB saat proses booting dimulai.

1
Sisihkan minimal 50GB ruang kosong via Disk Management.
2
Tulis citra ISO ke USB flashdisk menggunakan Rufus atau Ventoy.
3
Boot dari USB dan pilih opsi "Install alongside Windows".
Catatan: Cadangkan data penting sebelum memodifikasi tabel partisi.
