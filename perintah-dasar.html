FILESYSTEM HIERARCHY STANDARD (FHS)

Struktur Direktori Tunggal Linux

Seluruh partisi dan perangkat penyimpanan dipetakan di bawah satu akar direktori tunggal: / (Root).

/
Akar utama seluruh hierarki sistem file.
/home/user
Direktori kerja dan berkas pribadi pengguna.
/etc
Berkas konfigurasi sistem dan layanan daemon.
/bin
Program biner esensial (ls, cp, bash).
/var/log
Catatan log aktivitas kernel dan aplikasi.
/dev
Representasi perangkat keras sebagai file.

PERINTAH FUNGSI & KEGUNAAN CONTOH SINTAKS AKSI CEPAT
pwd Print Working Directory: Menampilkan jalur direktori aktif saat ini. pwd
ls List: Menampilkan daftar berkas, folder, serta atribut izin aksesnya. ls -la
cd Change Directory: Berpindah antar-direktori (cd .. atau cd ~). cd proyek
mkdir Make Directory: Membuat direktori baru di lokasi aktif. mkdir folder_baru
touch Membuat berkas kosong baru atau memperbarui stempel waktu berkas. touch catatan.txt
cat Concatenate: Membaca dan mencetak isi berkas teks ke stdout terminal. cat readme.md
rm Remove: Menghapus berkas secara permanen (tambahkan -r untuk folder). rm catatan.txt
whoami Mencetak nama akun pengguna efektif yang sedang menjalankan sesi. whoami
uname -a Menampilkan informasi versi kernel, hostname, dan arsitektur prosesor. uname -a
df -h Disk Free: Memeriksa alokasi kapasitas partisi penyimpanan dalam format terbaca. df -h
neofetch Mencetak ringkasan spesifikasi sistem operasi beserta logo ASCII distribusi. neofetch
