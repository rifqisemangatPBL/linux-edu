FILESYSTEM HIERARCHY STANDARD (FHS)

Di Mana File Anda Disimpan di Linux?

Berbeda dengan Windows yang menggunakan drive C: dan D:, seluruh sistem file Linux berakar pada satu garis miring tunggal: / (Root).

/
Akar utama dari semua folder dan drive.
/home/user
Folder pribadi Anda (Dokumen, Download, Proyek).
/etc
File konfigurasi sistem & aplikasi.
/bin
Program executable dasar (ls, cp, bash).
/var/log
Catatan log aktivitas & error sistem.
/dev
Perangkat hardware fisik yang direpresentasikan sebagai file.

PERINTAH FUNGSI & KEGUNAAN CONTOH SINTAKS AKSI CEPAT
pwd Print Working Directory: Mengetahui folder aktif saat ini. pwd
ls List: Menampilkan daftar isi file dan folder di direktori. ls -la
cd Change Directory: Berpindah folder (misal: cd .. atau cd ~). cd proyek
mkdir Make Directory: Membuat satu atau lebih folder baru. mkdir folder_baru
touch Membuat file teks baru yang masih kosong. touch catatan.txt
cat Concatenate: Membaca dan menampilkan isi file ke layar. cat readme.md
rm Remove: Menghapus file permanen (gunakan -r untuk folder). rm catatan.txt
whoami Mengetahui identitas nama user yang sedang login. whoami
uname -a Menampilkan versi kernel Linux dan arsitektur CPU. uname -a
df -h Disk Free: Memeriksa sisa ruang penyimpanan partisi hard disk. df -h
neofetch Menampilkan ringkasan spesifikasi sistem dengan maskot Tux. neofetch
