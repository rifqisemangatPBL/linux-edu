# Tiga Pilar Garis Keturunan Utama

KELUARGA DEBIAN Format: .deb

Debian / Ubuntu Lineage

Ekosistem paling luas dengan manajer paket apt. Menjadi basis bagi Ubuntu, Linux Mint, Pop!_OS, dan Kali Linux.

Karakter: Stabilitas tinggi, dukungan perangkat keras luas.
KELUARGA RED HAT Format: .rpm

Fedora / RHEL Lineage

Standar server enterprise dan infrastruktur perbankan menggunakan manajer paket dnf serta keamanan SELinux.

Karakter: Adopsi teknologi upstream dan container modern.
ARCH pacman

Rolling Release

Perakitan sistem modular dengan pacman dan repositori komunitas AUR.

Karakter: Pembaruan berkelanjutan tanpa rilis versi mayor.

Katalog Distro Populer

Saring distribusi berdasarkan profil penggunaan dan spesifikasi perangkat keras

Standar Perintah Lintas Distribusi

Meski manajer paketnya berbeda (apt, dnf, pacman), seluruh distro berbagi sintaks Shell POSIX yang identik (cd, ls, pwd, mkdir, touch, cat, rm). Praktikkan langsung di Modul 04.
