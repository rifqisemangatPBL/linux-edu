Memahami Garis Keturunan & Ragam Distro

Distro adalah racikan lengkap: Kernel Linux + Software GNU + Desktop Environment + Package Manager. Masing-masing dikembangkan dengan filosofi dan sasaran pengguna yang berbeda.

# 3 Pilar Garis Keturunan Utama Linux

KELUARGA DEBIAN Paket: .deb

Debian / Ubuntu Lineage

Paling ramah pengguna di bumi. Menggunakan package manager apt. Melahirkan Ubuntu, Linux Mint, Pop!_OS, dan Kali Linux.

Kunci: Sangat stabil, dokumentasi melimpah, komunitas terbesar.
KELUARGA RED HAT Paket: .rpm

Fedora / RHEL Lineage

Standar industri enterprise dan server perbankan/cloud. Menggunakan package manager dnf. Mengedepankan teknologi open source terdepan.

Kunci: Keamanan SELinux, integrasi container, modern upstream.
KELUARGA ARCH Paket: pacman

Arch / Rolling Release

Dirancang untuk pengguna yang ingin merakit OS dari nol (Do It Yourself). Menggunakan package manager pacman dan repository AUR legendaris.

Kunci: Selalu update ke versi software paling mutakhir tanpa install ulang.

HUBUNGAN KE MODUL BERIKUTNYA

Satu Bahasa yang Menghubungkan Seluruh Distro

Meskipun Ubuntu menggunakan apt, Fedora menggunakan dnf, dan Arch menggunakan pacman, semuanya memiliki satu kesamaan mutlak: Perintah Inti Shell POSIX (cd, ls, pwd, mkdir, touch, cat, rm) bekerja dengan cara yang 100% sama di semua distro! Mari kita latih langsung di Modul 4.
